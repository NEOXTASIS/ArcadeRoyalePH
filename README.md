# Arcade Royale PH

A mobile-friendly experimental arcade prototype.

## Included
- Responsive arcade homepage
- Lucky Drop, Reel Rush, and Reflex Pop browser demos
- Fictional demo scores and illustrative reward showcase

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying.

## Important
This is an entertainment prototype only. Credits and scores are fictional and have no monetary value. They cannot be purchased, transferred, withdrawn, or redeemed. No deposits, wagers, cash prizes, or real-world prize claims are supported. Obtain qualified Philippine legal and regulatory advice before adding paid chance-based play or prizes of value.
